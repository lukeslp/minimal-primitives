How to play

Draw lines to split the board into shapes. Each shape needs exactly one dot.

●

Each shape must look the same after a half-turn around its dot.

Tap a line to add or remove it. Drag to change several lines at once.

Tap inside a shape to see it turned around its dot. Squares that don’t match turn striped. A striped line has the same shape on both sides, so remove it.

Keyboard

Tab to a line. Enter or Space adds or removes it. Arrow keys move between lines. R checks the shape beside it. Z undoes. Escape cancels a drag.
