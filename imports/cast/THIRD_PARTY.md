# Local dependencies

- Three.js 0.183.2, MIT. Unmodified local modules; see vendor/LICENSE-THREE.txt.

The module is the same copy that Simple Machines ships. No CDN or external runtime dependency is required, and no Three.js add-ons are used: the bevelled cube, the shading, the contact darkening and the shadow filter are original.

Primary upstream reference:
- https://threejs.org/
